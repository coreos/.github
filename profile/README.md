# CoreOS

## The container optimized OS

We are building minimal Operating Systems (RHEL CoreOS, Fedora CoreOS) focused on running containerized workflows, with a focus on security, scalability and automatic updates.

We are using [OCI containers as a transport and delivery mechanism for operating system content](https://containers.github.io/bootable/).

Our goal is to build a community interested in minimal, secure and scalable operating systems.
